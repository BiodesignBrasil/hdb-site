# Health Data Brasil · site público

Síntese navegável do projeto **Health Data Brasil**: coortes a partir das bases públicas de saúde do Brasil, cruzadas pela mesma pessoa, com a análise pronta para quem decide.

Publicado pelo GitHub Pages em **https://biodesignbrasil.github.io/hdb-site/**.

| Caminho | O que é |
|---|---|
| `/` | página de entrada, com um link para a Sistemática |
| `/sistematica/` | **Sistemática em quatro camadas**: quem paga e quem ganha · capacidade e demanda · o que se oferece · o que o cliente vive. Sem valores em reais. |

Este repositório contém **só o que o site serve** (`.html`, `.css`, `.js`). Os dados, as planilhas, as notas e os registros do projeto ficam no vault privado `BiodesignBrasil/health-data-brasil`; os arquivos daqui são **gerados** a partir dele por `08_sintese/dados/publica_fronts.py`, que roda um detector de vazamento antes de copiar. Não editar os arquivos publicados à mão: a próxima publicação os sobrescreve. O único arquivo editado aqui diretamente é este README.
